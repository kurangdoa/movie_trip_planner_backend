# 🎬 Movie x Airbnb Vibe Matcher Backend

An AI orchestration service powered by PydanticAI and Gemini that extracts the visual DNA of movies and finds real-world Airbnb stays matching that cinematic aesthetic.

## 🏗️ Architecture & Platform Prerequisites

This backend service runs alongside independent platform containers connected via shared Docker bridge networks:

* **ChromaDB**: Dedicated vector database running in this stack storing Airbnb listing embeddings.
* **Langfuse (`platform_langfuse`)**: Real-time LLM observability, call tracing, latency tracking, and prompt versioning.
* **MLflow (`platform_mlflow`)**: Experiment tracking and prompt artifact registry via `mlflow.pydantic_ai.autolog()`.
* **Caddy Gateway (`platform_gateway`)**: Reverse proxy handling external routing and SSL termination for `movie-trip.kurangdoa.com`.

## 🔑 Langfuse Project Tracing Setup (Pre-requisite)

Langfuse routes all traces and prompt registry requests based strictly on the provided API keys:

1. Log into your Langfuse dashboard at `https://langfuse.kurangdoa.com`.
2. Create or select your project (e.g., `movie-trip`).
3. Navigate to **Project Settings** $\rightarrow$ **API Keys** and generate a new key pair.
4. Add the generated keys to your backend `.env` file. Any trace generated by the agent will automatically bind to that project.

### Environment Configuration

Create a `.env` file in the root directory:

```env
# Langfuse Observability
LANGFUSE_PUBLIC_KEY="pk-lf-..."
LANGFUSE_SECRET_KEY="sk-lf-..."
LANGFUSE_BASE_URL="https://langfuse.kurangdoa.com"
```

## Run

To run, first do the `make up` to spin up the resources.

After that follows by ingest data with `make pipeline_docker_ingestion_airbnb`

Finally, `make pipeline_docker_vector_airbnb` is to index the data above and put it into vector database.

```
make up
make pipeline_docker_ingestion_airbnb
make pipeline_docker_vector_airbnb
```
